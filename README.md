"The Funniest Office Joke, Judged Head to Head" — $2 USDC prize, judged
head to head in blind rounds.

## The joke

> My office badge worked on every door except my own office, so security gave me a visitor pass to my own desk — I've been a guest here for three years now.

## Run

```sh
python3 main.py
```

Writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`),
validated against the contest gate: 1–200 characters, single line, no
trailing newline. No network, no dependencies.
